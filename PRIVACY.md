# Privacy

AI Conversation Index is self-hosted software. It does not include telemetry, analytics, advertising, or a hosted data service.

Conversation text, metadata, attachments, summaries, embeddings, cursors, and imports are stored in the operator-selected data home. Data leaves that host only when the operator explicitly transfers a backup, configures an MCP client, or runs an external provider collector.

The software does not require browser cookies, browser local storage, authentication headers, passwords, or private provider APIs. App-assisted collectors must use supported signed-in application tools and reject incomplete transcripts.

Operators control retention by deleting their local data home and backups. Uninstalling the plugin does not delete conversation data automatically.
